# Project 2 — Student Grade Calculator

## Purpose

Practice loops and methods by calculating grades for multiple students or assessments.

## Requirements

Read a count of scores, validate each score, calculate a total and average, then map the average to a grade band. Keep input, calculation, and display steps in separate methods as the project grows.

## Inputs and outputs

Input: number of scores and each score. Output: validated scores, average, and grade.

## Validation rules

Count must be positive; scores must be within the chosen 0–100 scale. Handle malformed input deliberately.

## Concepts practiced

Loops, methods, parameters, return values, overloading, scope, and condition ordering.

## Suggested milestones

1. Calculate one score's grade.
2. Repeat for a fixed number of scores.
3. Extract average and grade conversion into methods.

## Edge cases

Empty input, one score, exact grade thresholds, and out-of-range scores.

## Optional extensions

Weighted categories, highest/lowest score, and a retrying menu.

## Review questions

Why should the average method return a value? How do you avoid integer division truncation?
