# Week 1 Challenges — Fundamentals

The existing [Main.java](Main.java) contains current Week 1 switch exercises. Preserve it as your working practice file; the Bill Splitter project is separately documented [here](../../projects/01-bill-splitter/README.md).

Try these without looking up a complete solution:

1. Extend the switch examples with one more day and one more role.
2. Predict the result of integer division and string concatenation before running a snippet.
3. Debug a string comparison that uses `==` where `.equals()` is needed.
4. Add input validation to a small prompt and explain what happens for boundary values.

Compile from this directory with `javac Main.java`, then run `java Main`.
